# React Components Practice

A Vite + React practice app demonstrating reusable components, props, state, events, and an accessible sample form.

From this folder, run `npm install`, then `npm run dev` to start the app. Run `npm run build` to create and verify the production build.

The reusable `Header`, `Footer`, `Card`, `Button`, and `Form` components are in `src/components/`. The counter and sample form are local demos; the form does not send or store submissions.
